      一、市場環境與主持人核心觀點

      多空研判： [牛中帶熊] 指數與那斯達克期貨均創新高，弱勢族群也開始回穩，主持人認為此時直接轉空像是在「摸頭」；但連假前市場仍有不確定性，部分題材也已出現誇張數字與 FOMO 情緒，需提防追高後的回檔重擊。

      資金輪動方向：

      • 過去「連狗都不要」的光通訊率先發動，成為類股輪動的第一棒。
      • 先前經歷大幅修正、長時間躺在低檔的被動元件，近期開始慢慢站回來。
      • Meta Muse 引發 Agentic AI 討論後，美股 CPU 相關股票先漲，隔日台股 CPU 族群也出現漲停或強勢表現。
      • 主持人認為，只要指數持續創高，資金就可能從既有強勢股擴散至落後族群，市場熱度與 FOMO 情緒有機會在連假後進一步回升。
      • DSP 則因高速交換器與光模組升級、供應吃緊及漲價傳聞，成為另一個開始升溫的題材。

      整體操作哲學：

      • 主持人習慣維持八至九成以上部位，不喜歡僅因主觀預測轉空就全面空手。
      • 判斷空頭要「眼見為憑」：例如指數真正破底、眾多個股明確轉空，而不是自己短線交易不順，就推論整體市場已經轉壞。
      • 長期而言，主持人仍認為資金放在股票市場較有機會取得良好報酬；現金只有在急跌時短暫展現價值，若未及時重新投入，可能錯失更大的上漲行情。
      • 題材操作上不否定趨勢，但要區分第一波與第二波催化。第二次催化仍可能推升股價，激情通常不如第一波，之後仍要回到營收與獲利驗證。
      • 對市場流傳的極端數字保持懷疑。趨勢可能正確，不代表最樂觀的用量假設與估值也合理。

      本集最重要的產業主軸：

      1. Agentic AI 與 CPU： Meta Muse 讓市場重新注意 AI Agent 工作流程中的 CPU 用量。主持人引用 AMD、Bernstein 與 Arm 的產業說法，認為 CPU 相對 GPU 的配置比例確有上升空間，但市場流傳的 CPU 對 GPU「40 比 1」缺乏合理依據；現階段以 1 比 4至1 比 2較接近共識，1 比 1屬偏樂觀情境。
      2. 高速光通訊 DSP： 隨交換器與光模組由 400G、800G走向1.6T，訊號處理難度增加，DSP 的必要性與價值提升。現階段供應偏緊、漲價具合理性；不過中長期仍要觀察 LPO、CPO 等新架構的替代影響，不能用零和思維過早判定既有廠商將被淘汰。
